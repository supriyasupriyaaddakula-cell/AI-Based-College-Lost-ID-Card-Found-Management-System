# 🤖 AI-Based College Lost ID Card & Found Management System

## 📌 Project Overview

The AI-Based College Lost ID Card & Found Management System is a web application designed to help college students report lost and found ID cards and identify possible matches quickly.

The system uses AI-based text similarity to compare descriptions of lost and found ID cards.

## 🎯 Objectives

- Report lost college ID cards
- Report found college ID cards
- Match lost and found reports using AI
- Reduce manual searching time
- Maintain records using a database
- Provide a simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Sentence Transformers

## ✨ Key Features

- 📊 Dashboard
- 🔴 Report Lost ID
- 🟢 Report Found ID
- 🤖 AI-Based Matching
- 📋 View All Reports
- ✅ Mark ID as Returned
- 🗑️ Delete Reports
- 📥 Export Data as CSV

## 🧠 AI Matching

The system uses the Sentence Transformer model to convert text descriptions into numerical embeddings.

These embeddings are compared to calculate similarity between lost and found ID card descriptions.

A higher similarity score indicates a stronger possible match.
